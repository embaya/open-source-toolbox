# Taxonomy

## Priority

- **A** — strategic/high-value, inspect first.
- **B** — useful reusable component/reference.
- **C** — niche, educational, legacy or situational.

## Recommended decision actions

- **DEPLOY** — run largely as-is.
- **INTEGRATE** — consume as a library, service, protocol endpoint or component.
- **EXTEND** — adapt/fork and add project-specific behavior.
- **INSPIRE** — reuse patterns, architecture, prompts or workflows.
- **LEARN** — use for documentation, examples or education.
