# Claude Code context

Before designing or implementing a new capability, read `AI_CONTEXT.md` and consult this repository's catalog.

Prefer:

```bash
python scripts/query_catalog.py --query "<capabilities and keywords>" --limit 12
```

Then shortlist candidates and decide whether to **DEPLOY, INTEGRATE, EXTEND, INSPIRE, LEARN, or IGNORE** them.

Do not build a major component from scratch until you have checked `catalog.jsonl`.

For project-wide architectural decisions, also read `TOP_PICKS.md` and `STACKS.md`.
