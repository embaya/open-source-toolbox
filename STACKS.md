# Reusable Project Stacks

Known combinations to use as starting points, not rigid prescriptions.

## Agent Platform / Multi-Agent OS

**Goal:** Construire le socle commun de stacks et agents

**Repositories:** Agent-Field/agentfield; agentscope-ai/agentscope; TencentCloud/CubeSandbox; thedotmack/claude-mem; openobserve/openobserve

**Why:** AgentField pour exécution, AgentScope pour orchestration, CubeSandbox pour isolation, Claude-mem pour mémoire, OpenObserve pour observabilité.

**Suggested action:** Commencer par un POC avec 2–3 briques, puis ajouter mémoire et observabilité.
